# 쪽지 뽑기

종이 쪽지에 적힌 단어 중 하나를 무작위로 뽑는 웹앱입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 사용법

1. **단어 등록**
   - 텍스트: `사과, 바나나 / 포도` 처럼 `,` 또는 `/`(줄바꿈도 가능)로 구분하면 각각 다른 쪽지가 됩니다.
   - 엑셀: `.xlsx` / `.xls` / `.csv` 파일을 선택하거나 끌어다 놓으면 값이 있는 칸마다 쪽지 한 장이 만들어집니다 (모든 시트).
   - 쪽지 옆 `×`로 개별 삭제, **단어 목록 초기화**로 전체 삭제.
2. **뽑기** – 쪽지가 섞이다가 한 장이 화면 중앙으로 나와 펼쳐집니다.
3. 결과 아래 버튼
   - **다시 뽑기**: 방금 뽑힌 쪽지를 후보에 그대로 둔 채 다시 뽑습니다.
   - **추가로 뽑기**: 방금 뽑힌 쪽지를 후보에서 빼고 다시 뽑습니다. 빠진 쪽지는 목록에서 취소선으로 표시되며, **모두 후보로 되돌리기**로 복원할 수 있습니다.

등록한 단어는 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.

## 파일 구성

- `index.html`, `style.css`, `app.js` – 앱 본체
- `vendor/xlsx.full.min.js` – 엑셀 파일 파싱용 [SheetJS](https://sheetjs.com) 0.18.5 (Apache-2.0, `vendor/xlsx.LICENSE`)
